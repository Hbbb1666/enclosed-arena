# 禁闭空间 · 公寓三维模型

变格狼人杀长篇设定的空间建模：一公里见方的禁闭地被，正中一座占掉一半面积的合院公寓，外场是花园与喷泉广场。
纯静态页面，双击 `index.html` 即可打开，依赖 three.js 的 CDN。

## 交互

- 拖拽旋转，滚轮缩放，右键（或 Shift + 拖拽）平移。
- 视角预设：全景 / 俯瞰 / 楼层剖面 / 中庭 / 外场。
- 图层开关：边界屏障、公寓外墙、屋顶、花园、广场、夜间、自动旋转。
- `楼层展开` 滑块把楼板逐层拉开，鼠标悬停任意楼层会显示层号、用途与住户。
- 点任意房号按钮，镜头会飞到该层并高亮楼板。

## 空间参数

| 项目 | 数值 |
| --- | --- |
| 禁闭空间 | 圆形，直径 1 000 米，边界为不可毁的透明屏障 |
| 公寓 | 465 × 465 米，含 140 × 140 米中庭，占地约 25.0% |
| 层数 | 地上 14 层，首层挑高 11 米，其余每层 8 米，总高 115 米 |
| 护城河 | 环绕公寓的方形水环，宽 26 米，四座石桥对着四个门廊 |
| 外场 | 四条林荫大道、四座喷泉广场、四座方尖碑、规整花园（花坛 · 修剪绿篱 · 柱形柏 · 修剪球 · 长椅）、外圈环形散步道 |

层高按放大后的示意尺度给了 8 米：按真实的 3.6 米建模，一千米场地缩进屏幕后窗格只有两三个像素，看不清；
放大层高与窗洞之后，默认视角不动手缩放就能数清每一层的窗户。

## 文件

- `index.html`：整座禁闭地的一公里三维模型。
- `model.fragment.html`：上面那个模型的源文件（片段形式）。
- `floors.html`：公寓内部的楼层分解模型，八块楼板并排摆开，可单独抽出某一层细看。
- `floors.fragment.html`：楼层分解模型的源文件。

源文件改完之后，用可视化脚本重新导出即可覆盖对应的 `*.html`。
