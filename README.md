# 禁闭空间 · 公寓三维模型

变格狼人杀长篇设定的空间建模：一公里见方的禁闭地被，正中一座占掉一半面积的合院公寓，外场是花园与喷泉广场。
纯静态页面，双击 `index.html` 即可打开，依赖 three.js 的 CDN。

## 交互

- 拖拽旋转，滚轮缩放，右键（或 Shift + 拖拽）平移。
- 视角预设：全景 / 俯瞰 / 楼层剖面 / 中庭 / 外场。
- 图层开关：边界屏障、公寓外墙、屋顶、花园、广场、夜间、自动旋转。
- `楼层展开` 滑块把楼板逐层拉开，鼠标悬停任意楼层会显示层号、用途与住户。
- 点任意房号按钮，镜头会飞到该层并高亮楼板。

## 空间参数

| 项目 | 数值 |
| --- | --- |
| 禁闭空间 | 圆形，直径 1 000 米，边界为不可毁的透明屏障 |
| 公寓 | 650 × 650 米，含 170 × 170 米中庭，占地约 50.1% |
| 层数 | 地上 14 层，一层挑高 6 米，其余每层 3.6 米，总高 52.8 米 |
| 外场 | 四边环带最宽 175 米，四座喷泉广场、四座方尖碑、外圈环形散步道 |
